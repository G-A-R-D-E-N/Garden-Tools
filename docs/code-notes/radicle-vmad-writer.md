# Stored VMAD authoring

`Radicle/src/schema/vmad.cpp:read_property` records value byte ranges while using the existing checked parser. `Radicle/src/plugin/vmad_writer.cpp:set_vmad_property` uses those ranges to patch known scalar types and existing simple array elements without changing property types, flags, counts, names, padding or fragment-tail bytes. Source: pinned xEdit 93cc0bc5 `wbDefinitionsFO4.pas:wbScriptProperty`, `wbScriptPropertyObject` and `wbVMAD` (lines 3724–3891), plus the existing reader grammar. Object formats 1/2 and writer versions 5/6 are explicitly supported; other layouts are refused.

`Radicle/include/fo4/c_api_vmad.h` exposes the typed setters; `Radicle/bindings/csharp/Radicle.Interop/PluginFile.cs` uses the same native mutations. String values are stored as the UTF-8 bytes given to the setter (`Radicle/src/c_api_vmad.cpp:radicle_plugin_set_vmad_string`, notes in `Radicle/docs/code-notes/Radicle.md`); property names keep the Windows-1252 boundary in `Radicle/src/c_api_placed.cpp:build_view`. Unknown type 6, nonempty type 16, unparsed tails, property-list structure and recursive struct authoring remain preserved or refused. The existing verified variable-layout evidence remains in `Radicle/docs/VMAD_VARIABLE_EVIDENCE.md`; no new runtime behavior is asserted.

`Radicle/include/fo4/c_api.h:RADICLE_ABI_VERSION` advances main ABI 29 to 30 for the five existing VMAD setters. The main merge preserves the published reader/writer behavior and both parents' exports and regenerates bindings/probes rather than merging generated text. Type 6, nonempty type 16 and unsupported tails retain their fail-closed refusal; runtime binding, third-party specimens, NG and CK proof remain open in #15/#388. Parallel ABI branches need a re-bump if another ABI change lands first.

Bool writes: `Radicle/src/plugin/vmad_writer.cpp:encode_value` overwrites any stored byte with 0 or 1 and does not refuse a stored value above 1. This matches xEdit `wbDefinitionsFO4.pas:3774` (`wbInteger('Bool', itU8, wbBoolEnum)`, which has no stored-value check). Covered by `Radicle/tests/test_vmad_writer.cpp:VmadWriter.BoolWriteReplacesAnyStoredByteWithZeroOrOne`.
