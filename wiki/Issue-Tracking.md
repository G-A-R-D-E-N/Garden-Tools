# Issue Tracking

This page lists every problem found while reviewing GARDEN-TOOLS PRs: whether it is still open, how it was fixed, and the evidence. Before working on an area, check here. When a PR fixes or changes something listed, update the row.

## How to use this page

- **Before fixing anything:** search this page for the file, symbol or PR. An entry may already record the decision, the evidence, or a fix that was tried and withdrawn.
- **After a review:** add each confirmed finding as a new row with the next free ID. Record withdrawn and rejected findings too, so they aren't raised again.
- **When a fix lands:** set the status, and record the fixing PR and commit. Mark a row **Verified** only after someone has re-reviewed the fix at that commit.
- **Evidence:** cite pinned sources. xEdit means TES5Edit/TES5Edit on GitHub at the stated commit, quoted by path, symbol and line range; never from memory. The private RE repo is cited by commit and section. Never use absolute local paths.

### Status values

| Status | Meaning |
|---|---|
| Open | Confirmed; no fix pushed |
| Prompt issued | A fix has been handed to an agent; no commit yet |
| Fix pushed | A commit claims to fix it; not yet re-reviewed |
| Verified | The fix was re-reviewed at the stated commit |
| Merged | Verified, and the fix is on `main` |
| Accepted | A known limitation, deliberately left as is |
| Withdrawn | The finding was wrong; the evidence is recorded so it isn't raised again |

### Severity

**High:** data loss, corruption, or a broken build or consumer. **Medium:** wrong behaviour a user can hit. **Low:** inconsistent messages, test gaps, docs.
